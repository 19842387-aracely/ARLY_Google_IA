JavaScript

El lenguaje que hace que una página responda a lo que hace la persona que la visita.

¿Qué es?

JavaScript permite agregar comportamiento a una página: responder a clics, cambiar contenido, validar formularios, controlar animaciones y trabajar con datos.

HTML + CSS + JavaScript

HTML estructura el contenido. CSS define su apariencia. JavaScript decide qué sucede cuando interactuamos con la página.
