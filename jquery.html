jQuery

Una biblioteca de JavaScript que popularizó una forma corta de seleccionar elementos y crear efectos.

¿Para qué sirve?

jQuery simplifica tareas frecuentes como seleccionar elementos, escuchar eventos y aplicar efectos. Hoy JavaScript moderno puede hacer muchas de estas tareas sin biblioteca, pero jQuery sigue apareciendo en proyectos existentes.

Sintaxis

$("#coleccion").slideToggle();
$(".producto").fadeIn();

Ventajas

  • Sintaxis breve.
  • Mucho material histórico disponible.
  • Útil al mantener sitios antiguos.

Desventajas

  • Añade una dependencia.
  • Para proyectos nuevos, JavaScript nativo suele ser suficiente.
