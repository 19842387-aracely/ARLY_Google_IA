# ARLY — Proyecto web

## Qué incluye
- Página principal de ARLY.
- Imágenes originales en SVG dentro de `img/`.
- Bootstrap 5.
- Carrusel Bootstrap con `carousel-fade` (crossfade).
- JavaScript para modo claro/oscuro, navegación suave, animaciones al aparecer y cuestionario.
- Páginas de investigación: JavaScript, jQuery, JSON y Hosting/Dominios.
- Nueva página `herramientas-google.html` con 15 herramientas de IA de Google.
- Cuestionario interactivo.

## Cómo abrirlo
Abre `index.html` en el navegador. Bootstrap se carga desde CDN, por lo que para ver el carrusel y el menú responsive debes tener conexión a Internet.

## Publicarlo
Puedes subir esta carpeta a GitHub y después conectar el repositorio con Vercel.

## Investigación
La selección de herramientas fue preparada consultando páginas oficiales de Google y Google Labs. La disponibilidad gratuita no significa que todas las funciones sean ilimitadas: Google puede aplicar límites, disponibilidad regional, cuentas elegibles o planes de pago.
