JSON

Un formato de texto muy usado para intercambiar datos entre aplicaciones y servidores.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Organiza datos mediante pares clave-valor y estructuras como objetos y listas.

Objeto JavaScript

const joya = {
  nombre: "Collar",
  precio: 25
};

Cadena JSON

'{"nombre":"Collar","precio":25}'

¿Dónde aparece?

Cuando una aplicación consulta una API, el servidor puede responder con JSON. JavaScript puede leer esos datos y mostrarlos en la interfaz.
