Hosting y dominios

El camino que sigue una página desde los archivos del proyecto hasta una dirección que cualquier persona puede visitar.

¿Cómo llega una web a Internet?

1. Guardas los archivos. 2. Los subes a un servicio de hosting. 3. Un dominio puede apuntar al servicio. 4. El DNS ayuda a encontrar el servidor.

Dominio → DNS → Hosting → Archivos HTML/CSS/JS → Navegador

Tipos

  • Compartido: varios sitios comparten recursos.
  • VPS: más control y recursos reservados.
  • Cloud: infraestructura flexible y escalable.

Vercel

Es una opción muy cómoda para publicar proyectos web conectados a GitHub, especialmente sitios estáticos y aplicaciones frontend.
